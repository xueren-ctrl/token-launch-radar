How the value is built

implied value = TVL × category multiple × growth × maturity × breadth

The category multiple is the median market-cap / TVL of the token-bearing protocols in the same category, computed from this snapshot at build time. Categories with fewer than 3 token-bearing peers fall back to the global median. Multiples are clamped to 0.05–2.00. Growth rewards upside more than it punishes downside (7d change clamped to −40%…+150%). Maturity rises with listing age up to 4 years. Breadth adds up to 20% for multi-chain protocols. No protocol name is ever special-cased.

What was left out, and why

Method: the board ranks every genuine pre-token protocol in the snapshot — all 40 watchlist codes plus every other protocol that records no token and is not a centralised exchange, a wrapped / staked / bridged product, or a versioned pool. Implied values follow from TVL, peer multiples, 7-day growth, listing age and chain breadth. Farm plans are templated by category and chain, never by protocol name.

Data: DefiLlama protocols snapshot, 14 November 2026, floor $50,000,000. This page is fully offline: no fetch, no external links, no tracking.
